# ⏳ Chrono Quest: 1-Minute RPG

**Chrono Quest** is a fast-paced micro-roguelike built entirely in pure Vanilla JavaScript and HTML5 Canvas. Players have exactly 60 seconds to navigate procedural dungeon grids, fight monsters, collect gold, level up, and descend as many floors as possible before time runs out.

---

## 🌟 Key Features

* **Zero Dependencies:** Built natively using pure HTML5 Canvas, CSS, and Vanilla JavaScript.
* **60-Second Challenge Loop:** Designed for high replayability with strict time limits.
* **Procedural Floor Generation:** Randomly generates walls, enemies, potions, chests, and stairs on every descent.
* **Turn-Based RPG Mechanics:** Features leveling up, combat stats, health management, and real-time combat logs.
* **Cross-Platform Controls:** Desktop arrow keys/WASD and mobile touch swipe controls.

---

## 🎮 How to Play

1. **Objective:** Descend as deep as possible into the dungeon and collect gold before the **60-second timer** hits zero.
2. **Icons Legend:**
   * ⚪ **White Circle:** Player Character
   * 🔴 **Red Squares:** Monsters (Engaging in combat costs HP, yields XP/Gold)
   * 🟢 **Green Orbs:** Health Potions (Restores HP)
   * 🟡 **Yellow Squares:** Treasure Chests (Grants Gold)
   * 🔵 **Cyan Square:** Exit Stairs (Descends to next floor)

---

## 🕹️ Controls

| Platform | Navigation |
| :--- | :--- |
